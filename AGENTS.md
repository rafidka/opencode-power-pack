# AGENTS.md

This repository is a growing collection of OpenCode configurations, agents,
commands, skills, plugins, and notes intended to improve a power-user workflow.

## Guidelines

- Keep additions focused, practical, and easy to understand.
- Prefer small, composable tools over broad frameworks.
- Follow OpenCode's documented file structure and configuration schema.
- Include brief setup or usage instructions when an addition is not self-explanatory.
- Never commit secrets, credentials, or machine-specific paths.
- Preserve existing behavior unless a change is intentional and documented.

As the repository grows, organize related additions by OpenCode feature and
update this file only when shared conventions are established.
